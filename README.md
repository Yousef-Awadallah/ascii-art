# ASCII Art
## Overview
This program prints an ASCII shape in the terminal based on input.  
For example, if the user enters 3, the below shape is printed:  
```text
*******  
 *****  
  ***  
   *  
  ***  
 *****  
******* 
```
## Implementation
- Written in C++
## Compilation
- Requires a C++ compiler  
```text
g++ ascii_art.cpp -o ascii_art
```
## Usage
To run the program:  
```text
./ascii_art
```
